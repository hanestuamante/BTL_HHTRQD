TÁI LẬP BẰNG PYTHON
Giải nén toàn bộ thư mục, không chỉ lấy notebook. Dùng Python 3.12.
Từ thư mục chứa Huong_dan.txt:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/prepare_data.py
python scripts/analyze.py
python scripts/build_notebook.py

Windows: thay lệnh source bằng .venv\Scripts\activate.
build_notebook.py thực thi mọi cell và lưu notebook có đầu ra.
Raw đã được đóng gói nên ETL mặc định không cần tải lại; checksum phải khớp.
Chỉ chạy prepare_data.py --refresh nếu chủ ý cập nhật nguồn và phân tích lại.
Để tạo lại Word sau khi EDA hoàn tất: python scripts/build_report.py.
Xuất PDF từ Word hoặc LibreOffice nếu cần tạo lại bản PDF sau chỉnh sửa.

GIỚI HẠN CẦN GIỮ KHI THUYẾT TRÌNH
1. Nhóm undervalued = giá < 0,8 trung vị từng dataset là nhóm giá thấp,
   chưa chứng minh bị định giá thấp so với giá trị hợp lý.
2. Ames gốc không có lat/long/zipcode; khoảng cách để thiếu có chủ đích,
   biểu đồ địa lý dùng neighborhood. Không tự điền tọa độ hoặc khoảng cách 0.
3. Haversine King dùng mốc Seattle do nhóm quy ước, đo đường chim bay.
4. Welch và Spearman King dùng 21.435 tài sản (lần bán sớm nhất),
   bảng mô tả/biểu đồ dùng 21.612 giao dịch. Không trộn hai mẫu khi trích số.
5. CSV sạch dùng EDA toàn mẫu. Khi dự báo, split trước rồi fit lại imputer,
   encoding, IQR; loại price_per_sqft, target alias và nhãn từ giá khỏi X.
6. Giá lịch sử USD, hai thị trường và định nghĩa diện tích khác nhau.
